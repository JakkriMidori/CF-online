# Cave Forge — เวอร์ชันออนไลน์ (เซิร์ฟเวอร์ของตัวเอง)

แอปเดียวทำสองอย่าง: เปิดหน้าเกม และเป็นห้องออนไลน์ให้เล่น PvP ข้ามเครื่อง
ใครมีลิงก์ก็เข้าเล่นได้ ไม่ต้องล็อกอิน Claude

- เครื่องคุณ **ไม่ต้องเปิดค้างไว้** เมื่อนำขึ้นคลาวด์แล้ว
- เซิร์ฟเวอร์ **ไม่เก็บเซฟ** เซฟเกมอยู่ในเบราว์เซอร์ของผู้เล่นแต่ละคน
- เซิร์ฟเวอร์ไม่คำนวณการต่อสู้ แค่ส่งต่อข้อความ เจ้าของห้องเป็นคนคำนวณ จึงใช้ทรัพยากรน้อยมาก

## ไฟล์ในชุดนี้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `server.js` | เซิร์ฟเวอร์ (เปิดหน้าเกม + ห้องออนไลน์ที่ `/ws`) |
| `package.json` | บอกว่าต้องติดตั้งอะไร (Node 18 ขึ้นไป + แพ็กเกจ `ws`) |
| `render.yaml` | ตั้งค่าสำเร็จรูปสำหรับ Render |
| `public/` | ไฟล์เกมทั้งหมด |

## ทางที่ 1: นำขึ้น Render (ฟรี แนะนำ)

1. สมัคร [GitHub](https://github.com) แล้วสร้าง repository ใหม่ อัปโหลดไฟล์ทั้งหมดในชุดนี้ขึ้นไป (ยกเว้นโฟลเดอร์ `node_modules` ถ้ามี)
2. สมัคร [Render](https://render.com) ด้วยบัญชี GitHub
3. กด **New → Web Service** แล้วเลือก repository นั้น
4. ตั้งค่า
   - Runtime: **Node**
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: **Free**
5. กด **Create Web Service** รอจนขึ้นว่า Live แล้วจะได้ลิงก์ เช่น `https://caveforge-xxxx.onrender.com`
6. ส่งลิงก์นี้ให้เพื่อน แล้วเล่นได้เลย

> แผนฟรีของ Render จะหลับเมื่อไม่มีคนใช้ประมาณ 15 นาที คนแรกที่เปิดจะรอประมาณ 30–60 วินาทีให้เซิร์ฟเวอร์ตื่น ถ้ากดสร้างห้องแล้วขึ้นว่าต่อเซิร์ฟเวอร์ไม่ได้ ให้รอสักครู่แล้วลองใหม่

## ทางที่ 2: รันบนเครื่องตัวเอง (ไว้ทดสอบ)

1. ติดตั้ง [Node.js](https://nodejs.org) รุ่น LTS
2. เปิด Terminal ในโฟลเดอร์นี้ แล้วพิมพ์
   ```
   npm install
   npm start
   ```
3. เปิด `http://localhost:3000`

เพื่อนในบ้านเดียวกัน (Wi-Fi เดียวกัน) เข้าได้ทาง `http://<IP เครื่องคุณ>:3000` ส่วนเพื่อนที่อยู่นอกบ้าน ใช้ทางที่ 1 ง่ายกว่า

## วิธีเล่นออนไลน์

1. คนที่ 1: ลานประลอง → ห้องออนไลน์ → **สร้างห้อง** แล้วจะได้รหัส 4 ตัว
2. คนที่ 2: ลานประลอง → ห้องออนไลน์ → ใส่รหัส → **เข้าห้อง**
3. คนที่ 1 กด **เริ่มสู้**

ถ้าหน้าห้องขึ้น "🌐 เชื่อมต่อเซิร์ฟเวอร์ Cave Forge แล้ว" แปลว่าใช้เซิร์ฟเวอร์นี้อยู่ ห้องหนึ่งรับได้ 2 คน

## เรื่องเซฟ

เซฟเก็บในเบราว์เซอร์ตามเว็บที่เปิด เซฟจากเกมบน claude.ai จึงไม่ย้ายมาเว็บใหม่โดยอัตโนมัติ และแต่ละเครื่องหรือแต่ละเบราว์เซอร์มีเซฟของตัวเอง

## อัปเดตเกมภายหลัง

แทนที่ไฟล์ในโฟลเดอร์ `public/` ด้วยไฟล์เกมรุ่นใหม่ แล้วอัปโหลดขึ้น GitHub อีกครั้ง Render จะ deploy ใหม่ให้เอง
